# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

部件经历component_id在更换时终止，新件使用新component_id。sensor_state=lost表示失联而非正常，signal为空不可当零。work_orders动作的replace、repair、clean、inspect有不同风险含义，effect不预置；scheduled_at为计划，done_at为实际落实，partial表示只清洁。维护价值应比较计划与非计划服务损失，safety_due是不可用经济收益抵消的最迟处理日。可用性指标按有服务承诺的小时计算，planned和unplanned停机分别可查但均影响实际可用。

## stations
区域站点与可用性承诺。

记录键：['station_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| station_id | string | 站 |
| region | string | 区域 |
| required_qualification | string | 资质 |
| target_availability | number | 目标 |
| loss_per_hour | number | 每停运小时损失 |
| shared_shock_group | string | 共同风险组 |

## components
部件完整经历，本包全部为thermal类型。

记录键：['component_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| component_id | string | 部件 |
| station_id | string | 站 |
| batch | string | 制造批 |
| start | date | 起日 |
| end | date | 止日 |
| end_reason | string | 更换或仍运行 |

## condition_readings
状态及有效运行暴露。

记录键：['reading_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| reading_id | string | 记录 |
| component_id | string | 部件 |
| date | date | 日 |
| signal | number | 状态测量 |
| sensor_state | string | observed或lost |
| operating_hours | number | 本段运行小时 |
| available_at | datetime | 可知 |

记录键：['failure_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| failure_id | string | 故障 |
| component_id | string | 部件 |
| occurred_at | datetime | 发生 |
| downtime_hours | number | 停运小时 |
| kind | string | 类型 |
| available_at | datetime | 可知 |

## work_orders
计划、落实和实际动作。

记录键：['order_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| order_id | string | 工单 |
| component_id | string | 部件 |
| created_at | datetime | 建立 |
| scheduled_at | datetime | 计划 |
| done_at | datetime | 完成 |
| action | string | 处置 |
| state | string | complete或partial |
| cost | number | 成本 |
| downtime_hours | number | 计划停运 |
| available_at | datetime | 可知 |

## windows
未来各站可用低负荷窗口；不同站可同日竞争。

记录键：['window_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| window_id | string | 窗口 |
| station_id | string | 站 |
| start | datetime | 开始 |
| hours | number | 时长 |
| loss_multiplier | number | 相对损失 |
| safety_due | date | 最迟处理 |

## crews
跨站共享班组。

记录键：['crew_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| crew_id | string | 班组 |
| qualification | string | 资质 |
| region | string | 区域 |
| hours_daily | number | 每日可用小时 |
| travel_hours | number | 跨站占用 |

## action_requirements
处置所需资源；pair_group相同需要同停机。

记录键：['component_type', 'action']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| component_type | string | 类型 |
| action | string | 动作 |
| hours | number | 工时 |
| part_id | string | 物料 |
| quantity | integer | 数量 |
| pair_group | string | 同停机组 |

## resources

记录键：['part_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| part_id | string | 物料 |
| quantity | integer | 数量 |
| reserved | integer | 其他已承诺 |

| 字段 | 类型 | 含义 |
| --- | --- | --- |

| available_at | datetime | 可知 |
